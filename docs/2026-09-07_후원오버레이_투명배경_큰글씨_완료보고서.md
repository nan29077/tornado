# 후원 오버레이를 투네이션 방식으로 — 배경 없는 큰 글씨

작성일: 2026-09-07 · 개발 완료

---

## 1. 바꾼 것

방송 화면에 **상자를 깔지 않는다.** 글자와 캐릭터만 얹는다. 투네이션·트윕·스트림엘리먼트가
모두 그렇게 하는 이유는 상자가 그 안의 장면을 가리기 때문이다.

| | 전 | 후 |
|---|---|---|
| 배경 | 420px 흰 카드 + 테두리 + 그림자 | **없음** |
| 본문 글자 | 16px | **64px** (1920 기준) |
| 메시지 글자 | 13px | **46px**, 최대 3줄 |
| 폭 | 420px 고정 | 최대 1340px, 내용만큼 |
| 정렬 | 가운데 | 왼쪽 |
| 가독성 | 배경 판이 담당 | **글자 테두리 + 그림자** |
| 금액 | 본문과 같은 색 | 테마별 강조색 |
| 캐릭터 | 배너 위 260px | 글자 **왼쪽** 200px |
| [감사합니다]·DONAIDO | 카드 아래 | 뺐다 (배경이 없으면 떠 보인다) |

## 2. 테마 4종

기본·미니멀·네온은 **모두 배경이 없다.** 색만 다르다.
예전 카드 디자인은 **카드형(CARD)** 으로 그대로 남겼다 — 상자를 원하는 크리에이터를 위해서다.

| 테마 | 모양 |
|---|---|
| **도네이도 기본** | 흰 글자 + 검은 테두리, 금액은 꿀색(#ffc632) |
| **미니멀** | 색을 쓰지 않음. 금액도 흰색, 굵기로만 구분 |
| **네온** | 형광빛 글로우, 금액은 시안(#22d3ee) |
| **카드형** (신규) | 예전 흰 카드 그대로 |

`theme` 은 DB 에 문자열로 저장되므로 **마이그레이션이 필요 없다.** 기존 값 `TORNADO` 는
그대로 두고 그 값이 그려지는 모양만 바꿨다. 모르는 값이 저장돼 있으면 기본으로 떨어진다.

## 3. 가독성을 어떻게 확보했나

배경 판을 없애면 밝은 장면(하늘·물·눈) 위에서 흰 글자가 사라진다. 판 대신
**글자 자신이 테두리를 두르게** 했다.

```
-webkit-text-stroke: 9px #17161a;
paint-order: stroke fill;      ← 테두리를 글자 뒤에 그린다
text-shadow: 0 8px 26px rgba(0,0,0,.55);
```

`paint-order` 가 없으면 두꺼운 테두리가 글자 속을 파고들어 획이 얇아 보인다.
OBS·PRISM 은 Chromium 기반이라 이 속성을 지원한다.

## 4. 크기 조절

크기 감각은 화면·거리마다 다르므로 한 번에 맞지 않는다.
**[위치·크기 조정]의 크기 슬라이더(50~150%)** 가 이 알림 전체에 그대로 적용된다.
64px 이 작으면 130% 로 올리면 83px 이 된다. 별도 설정을 만들지 않았다.

## 5. 함께 손본 것

- **조정 상자의 대략 크기**(`FALLBACK_BOX.donation`)를 새 디자인에 맞춰 넓혔다
  (가로 46%→64%, 세로 17%→30%). 옛 값 그대로 두면 [위치·크기 조정]의 상자가
  실제보다 훨씬 작게 그려져 끌 때 손에서 미끄러진다.
- **가장자리 여백** 24px → 72px. 방송 프로그램마다 화면 가장자리를 조금씩 자르는데,
  큰 글씨가 끝에 닿으면 잘려 보인다.
- **설정 화면의 작은 미리보기**도 실제와 같은 방식(테두리·상자 유무)으로 그린다.
  미리보기가 상자를 그리는데 실제는 안 그리면 고른 것과 다른 것이 방송에 나간다.

## 6. 손대지 않은 것

후원 결제·문자·정산, 표시 시간, TTS, 효과음, 금액 구간별 효과, 파티클 연출,
저장된 배치값의 범위와 변환 방식.

## 7. 검증

- 회귀 테스트 **40개 파일 534건 전부 통과** (신규 15건)
- `tsc --noEmit` 오류 0 · `eslint` 오류 0
- 실제 렌더 결과를 1920x1080 으로 캡처해 네 테마를 눈으로 비교함

신규 검사:

- 네 테마 값을 알아보고, 모르는 값·빈 값은 기본으로 떨어뜨린다
- 배경 판이 있는 테마는 CARD 뿐이다
- 글자에 테두리를 두른다 (`paint-order: stroke fill` 포함)
- 방송에서 읽히는 크기(64px / 46px)로 그린다
- 긴 메시지는 3줄로 끊는다
- 세 테마 정의에 배경색이 **하나도 없다**
- 예전 카드 디자인이 그대로 남아 있다
- 캐릭터가 배경 없는 알림에서는 옆에 200px 로 붙는다
- 설정 화면에 네 테마가 모두 있고, 미리보기도 같은 방식으로 그린다
