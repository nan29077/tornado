## 2. 반영한 결정 (기본안)

- 돈이 움직이는 관리자 작업(증액 조정, 일괄 지급완료, 은행 결과 반영, 계좌 실명확인, 수수료·한도 정책)은 **최고관리자·재무만** 가능. 운영 등급은 불가.
- 크리에이터 계정의 임시 비밀번호 발급·상태 변경은 **운영 등급 이상**. 고객지원은 후원자 계정만.
- 관리자 추가는 **초대 링크 방식**: 최고관리자가 초대 → 1회용 링크(72시간) → 초대받은 이메일 계정으로 로그인한 상태에서 수락해야 관리자. 메일 발송이 연동되지 않아 링크는 화면에 [MOCK] 표시와 함께 보여 주고 직접 전달한다.

## 3. 영역별 수정

### 결제·후원 (PAY)
- **PAY-A** 멈춘 결제 재시도는 시도 기록과 무관하게 **항상 결제사 결과조회 먼저**. 승인 요청 전에 "승인 진행 중" 기록을 남겨 서버가 중간에 죽어도 흔적이 남는다.
- **PAY-B** 회원 계정이 정지·탈퇴된 크리에이터는 문자 후원 접수·결제 단계에서 차단.
- **PAY-C** 결제수단 재등록 시 이전 빌키를 결제사에 해지 요청(실패하면 기존 재시도 배치가 이어받음).
- **PAY-D** 결제사 결과조회의 알 수 없는 코드(헥토 9999 포함)는 "실패"가 아니라 "미확인"으로 수동 대사.
- **PAY-E/F** 속도 제한·일·월 한도 되돌림 기준 시각을 예약 시각으로 맞춤, 음수 방지, PIN 취소·만료 시에도 되돌림.
- **PAY-G** 늦게 온 승인 결과가 관리자가 취소한 거래를 덮지 않음(덮어야 할 상황이면 위험 기록 + 관리자 알림).
- **PAY-H** 결제 실패 처리를 한 트랜잭션으로 묶고, "결제 진행중"에 멈춘 후원을 정리 배치가 1회만 마무리.
- **PAY-I** 밀린 문자 재처리 판정을 처리 시작 시각 기준으로, 오류 행 재사용은 조건부 선점.
- **PAY-J** 웹 PIN 진행 쿠키에 서명(위조·남의 후원 ID 사용 차단).
- **PAY-K** 운영에서 헥토 실연동 + 모의 PIN 조합이면 기동 차단(헥토 PIN 연동 전까지).
- 기타: 결제 타임아웃(AbortError) 분류, 없는 결제 통지 경로 수정.

### 정산·세무 (SET)
- **SET-A** 이체파일 잔액 검증에 **앞선 배치로 나갔지만 결과 대기 중인 금액**을 반영(재발급 건 이중 차감 없음).
- **SET-C** 정산 상태 전이 허용표(지급실패→바로 승인 같은 경로 차단), DB 갱신도 이전 상태 조건부.
- **SET-D** 이체파일 발급 시 승인 상태 재확인, 하나라도 어긋나면 전체 취소 + 409 안내.
- **SET-B** 이체파일이 나간 지급실패 건은 주민번호를 즉시 파기하지 않음(정정 대비). 끝내 실패로 남으면 90일 뒤 정리 배치가 파기.
- **SET-E** 세무관리 "신고 완료"도 주민번호 파기를 함께 처리.
- **SET-F** 사업자 크리에이터 정산 요청 화면은 원천징수 0원·전액 지급으로 표시.
- **SET-G** CSV 음수 금액 깨짐 수정, 줄바꿈(\r)·제어문자 처리(공용 `src/lib/csv.ts`).
- **SET-J** 결과 붙여넣기에 같은 요청이 두 줄 이상이면 전체 거절.
- **SET-K** 지급일 = 이체파일 발급일(결과 줄에 `YYYY-MM-DD` 이체일을 적으면 그 날짜).
- 그 밖에: 신고·처리자 기록 덮어쓰기 방지, 잘못된 월 값 거절, 신고 끝난 건이 지급실패로 바뀌면 `[수정신고 필요]` 표시, 결과 반영 버튼 권한 잠금.

### 게임 (GM)
- **GM-A** 결과 발표 상태에서도 설정 수정 차단(정답 바꿔 재발표 불가), 발표 취소도 설정이 바뀌었으면 거절.
- **GM-B** 퀴즈 빈 선택지 정리 시 정답 번호를 다시 맞춤(빈 칸을 정답으로 고르면 저장 거절).
- **GM-C** 환불 요청·완료 후원은 추첨·참여 인원·목표 게이지에서 제외.
- **GM-D** 지연 발행이 옛 회차 상태로 화면을 되돌리지 않음.
- **GM-E/F** 발표 취소 1회 제한을 동시 요청에도 보장, 발표와 참여 사이 경합 제거(회차 잠금).
- **GM-G** 사다리 출발·도착 개수가 다르면 저장 거절.
- **GM-H** 투표 동률은 "공동 1위"로 표시.
- **GM-I** 키워드 게임 진행 중 정답자 수 비공개.
- **GM-J** 발표 취소 가능 시간이 지나면 버튼 숨김, 유튜브 채팅 공유는 참여 중인 회차만.

### 오버레이·실시간 연결·음성 (SSE/OV)
- **SSE-A** 공유 연결기(v2): 생존 시간 150초로 여유, 구독을 정리할 때 화면에 끊김 신호 → 스스로 재연결, 화면이 다시 보이거나 뒤로가기 캐시에서 복원되면 구독 상태 확인. **170초 동결했던 탭이 복구 후 새 알림을 표시**하는 것을 실제 브라우저로 확인.
- **OV-A** 서버 음성 안전 시간이 지나면 앞 음성을 멈추고, 읽기 속도·실제 길이로 시간 계산(목소리 겹침 해소).
- **OV-B** 익명 후원은 연속 후원(콤보)으로 묶지 않음.
- **OV-C/D** 같은 알림의 음성 합성 동시 요청을 하나로 합침, 유효하지 않은 요청은 크리에이터 한도를 쓰지 않음(IP 별 한도).
- **OV-E** 게임 진행 화면의 공유 연결을 계정별로 분리.
- **OV-F** 보충 조회를 10초 겹쳐 읽어 알림 누락 방지.
- 그 밖에: 복구 알림 수 집계 수정, 콤보 종료 시 파티클 재폭발 방지, 아이콘 굵기 규칙 맞춤.

### 인증·보안·권한 (SEC)
- **SEC-A** 관리자 초대 링크 방식(위 2장). 다른 계정으로 로그인한 상태에서는 수락 버튼 대신 안내 표시.
- **SET-H / SEC-B** 위 2장의 권한 기준 적용.
- **SET-I** 계좌 실명확인은 관리자가 본 계좌(끝 4자리·수정시각)와 같을 때만.
- **SEC-C** 카카오·네이버 가입자가 크리에이터가 돼도 소셜 로그인 가능(관리자 계정은 소셜 로그인 불가 유지), 탈퇴 시 소셜 연결 삭제(같은 계정으로 재가입 가능).
- **SEC-D** 비밀번호 재설정 메일 미연동을 화면에 명확히 안내 + 운영 기동 경고.
- **SEC-E** 이메일 가입·크리에이터 신청 시 약관 동의 기록 저장.
- **SEC-F** 번호가 재배정된 경우 이전 사용자의 후원 이력이 번호 조회에 나오지 않음.
- **SEC-G** 고객센터 거래번호 안내 문구 통일(존재 여부 탐색 차단), 본인 거래만 문의에 연결.
- **CSRF** 쿠키 인증을 쓰는 변경 API(게임, 오버레이 배치, 알림, 문자 템플릿)에 같은 출처 검사.
- 그 밖에: 만료 세션 정리 배치, IP 미상 시 속도 제한 버킷 분리, 유튜브 재연결 빈 토큰 거절, 유튜브 연결 목록 상한, 답글 액션 오류 처리.

## 4. 시뮬레이션에서 추가로 고친 것
- 관리자 초대 링크를 다른 계정으로 열면 수락 버튼이 보였다(누르면 서버가 거절했지만 헷갈림) → 안내 문구로 대체.
- 문의 E2E 검사가 옛 문구("찾지 못해")를 기대 → SEC-G 통일 문구 기준으로 갱신.

## 5. 하지 않은 것 · 확인이 필요한 것
- **암호문 키 식별자(키 교체 구조)**: 기존 암호문 복호화 호환이 깨질 위험이 있어 하지 않았다. 알려진 한계로 둔다.
- **헥토 실연동 시 기동 차단(PAY-K)**: `PAYMENT_PROVIDER=hecto` 로 운영 기동하면 헥토 PIN 연동 전까지 서버가 뜨지 않는다(의도된 안전장치).
- **헥토 '9999'·온기 실패 코드**: 규격서 확인 전까지 "미확인"으로 처리해 수동 대사 건이 늘 수 있다.
- **운영 등급의 한도 정책 변경 불가**: 한도 정책도 돈 관련으로 묶여 운영 등급은 바꿀 수 없게 됐다. 다르게 원하면 알려 주시면 분리한다.
- **크리에이터 신청 연락 이메일**: 저장할 컬럼이 없어 저장하지 않는다(계정 이메일 선점 위험 때문에 계정 이메일에 넣지 않음).
- **`[수정신고 필요]` 표시**: 정산 처리 메모에 붙어 크리에이터 화면에도 보인다.
- **게임 회차 잠금(GM-F)**: 테스트 DB 특성상 실제 동시 잠금 경합은 운영 PostgreSQL 에서 한 번 더 보는 것이 좋다.
- **E2E 검사 스크립트 노후화**: 위 1장 참고.
- **미리보기 실행**: 새 마이그레이션이 있어 `1_미리보기실행.bat` 첫 실행 때 자동으로 적용된다(기존 데이터 유지).
