## 2. 요약

- 지금 바로 장애가 나는 화면이나 테스트 실패는 없다.
- 다만 **돈·공정성·권한과 관련된 숨은 결함**이 남아 있다. 대부분 평소에는 드러나지 않고, 특정 순서·동시 처리·운영 상황에서만 터진다.

| GM-J | [발표 취소] 버튼이 2분 제한 이후에도 보임, 유튜브 채팅 공유가 마감 회차에서도 참여 링크를 올림 | 조건부 표시 |
| SET-I | 정산 계좌 실명확인이 관리자가 본 계좌와 같은지 대조하지 않음(그 사이 계좌 변경 시 새 계좌가 인증됨) | 끝자리·수정시각 대조 |
| SET-J | 은행 결과 붙여넣기에 같은 요청의 성공·실패 줄이 같이 있으면 둘 다 적용 | 중복 줄 오류 처리 |
| SET-K | 지급일이 실제 이체일이 아니라 결과 반영 시각 → 월말 이체가 다음 달 원천징수로 잡힘 | 이체일 입력 또는 배치 발급일 |
| OV-C | 같은 알림에 음성 합성이 동시에 두 번 호출될 수 있음(OBS + 미리보기) → 비용 두 배 | 진행 중 요청 공유 |
| OV-D | 토큰이 유출되면 엉뚱한 이벤트 ID 요청으로 음성 합성 분당 상한을 소진시켜 방송 음성을 끊을 수 있음 | 허가 확인 후 상한 차감 |
| OV-E | 같은 브라우저에서 계정을 바꾸면 공유 게임 연결이 이전 계정 상태를 잠깐 보여 줄 수 있음 | 공유 키에 계정 구분 포함 |
| OV-F | Redis 전파 실패 시 보충 조회 기준 시각이 커밋 순서·서버 시계 차이로 알림을 건너뛸 수 있음 | 기준 시각을 몇 초 겹쳐 조회 |
| SEC-E | 이메일 가입·크리에이터 신청에서 약관 동의 이력이 저장되지 않음(소셜 가입은 저장) | 동의 기록 생성 |
| SEC-F | 휴대폰 번호 문자 조회가 번호 재배정 방어를 우회 → 번호를 물려받은 사람이 이전 사용자 후원 이력 열람 가능 | 재배정 프로필 제외 |
| SEC-G | 고객센터 폼으로 거래번호 존재 여부 확인 가능, 남의 거래가 문의에 연결됨 | 응답 통일, 본인 거래만 연결 |

### 3-4. 낮음 (정리·개선)

- 재연결 뒤 모든 후원이 "복구된 알림"으로 집계됨(미리보기 배지 숫자만 틀림)
- 콤보가 끝나는 순간 진행 중 파티클이 한 번 더 터짐
- 공유 연결 화면이 뒤로가기 캐시에서 복원되면 재구독 안 됨(SSE-A 와 함께 해결)
- 결제 타임아웃이 기록상 "오류"로 남음, 존재하지 않는 결제 통지 경로(`/api/payments/notify`) 설정
- 세무: 월 값이 잘못되면 조용히 이번 달로 처리, 신고·처리자 기록 덮어쓰기, CSV 줄바꿈(\r) 미처리, 결과 반영 버튼 권한 잠금 미반영
- 보안: 쿠키 인증 API 일부에 동일 출처 검사 없음(현재 쿠키 설정으로 외부 사이트 공격은 막힘), 만료 세션 정리 배치 없음, IP 를 모를 때 속도 제한 공용 버킷, 유튜브 재연결 시 빈 갱신 토큰 유지 가능(현재 mock), 암호문에 키 식별자 없음(키 교체 불가 구조)
- 게임 탭 아이콘 굵기 1.8(CLAUDE.md 기준 1.6~1.7)

## 4. 이상 없음으로 확인한 부분

- **결제**: 결제 진행권 선점(조건부 갱신 + 3분 리스), 승인 확정과 원장 적재 같은 트랜잭션, 보안 링크 1회 소비, PIN 콜백 원자 처리·서명 검증, 문자 수신 중복 방지(메시지 ID + 멱등키), 한도 재검사, KST 날짜·월 키, 로그 개인정보 마스킹
- **정산**: SET-1·2·14 수정 정상 동작, 원천징수 계산(소득세 3% 10원 미만 절사, 지방소득세 10%), 최소 출금 1만 원, 사업자 원천징수 제외(계산 로직), 지급·환입 분개 부호, 크리에이터 단위 잠금
- **오버레이**: 미리보기 전용 알림 방송 미송출, 퍼레이드 별도 수명, 미리보기 음소거, 음성 캐시, 투명 오류 화면, 알림 이중 재생 방지(서버·화면 양쪽), 대기열 멈춤 방지, XSS 없음, 금칙어 적용, 익명 처리 일관성, 다른 크리에이터 미리보기 차단, 장시간 방송 메모리 상한
- **게임**: 모든 추첨이 암호학적 난수(편향 없음), 정답 은닉(공개 API·SSR·SSE·샘플 모두), GM-1·2·5·6·7·8 수정 정상, 상태 전이 조건부 갱신, 사다리·룰렛 계산 일치, 10/6 커밋의 미리보기 상태 메시지 출처 검증
- **인증·보안**: 세션 토큰 해시 저장·httpOnly, 로그인 속도 제한 fail-closed, 로그인 후 이동 경로 검증, 관리자 액션 권한 허용 목록, 남의 데이터 접근(IDOR) 차단, 업로드 형식·크기·파일명 검증, raw SQL 파라미터 바인딩, 보안 헤더, 운영 필수 환경값 점검
